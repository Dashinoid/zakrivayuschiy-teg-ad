# Закрывающий тег

Проектная работа Яндекс Практикума: восемь этапов обучения с пиксельной иллюстрацией, CSS-фильтрами и анимированными лайками.

Репозиторий: https://github.com/Dashinoid/zakrivayuschiy-teg-ad

Макет: https://www.figma.com/design/Yg5IFeWSyl6Js98kWROjVP/

## Как открыть

Откройте `index.html` в браузере. Сервер, установка пакетов и интернет для работы сайта не нужны: изображения, шрифты и иконки сохранены в проекте.

## Что работает

- Восемь адаптивных карточек и семь разных CSS-фильтров, включая составной.
- Лайк по сердцу и по кнопке; текст переключается между Like и Unlike.
- Анимации заполнения сердца, увеличения и искр.
- Плавная заливка кнопок при наведении и выделение фокуса.
- Модальное окно «Сохранить на память»: закрытие по «Ок» и Escape.
- Поддержка клавиатуры, состояния aria-pressed и prefers-reduced-motion.

«Сохранить на память» открывает учебный диалог из макета. Эта кнопка не скачивает файл.

## Личные заметки

Второй абзац каждой карточки в `index.html` — согласованный черновик воспоминания. Перед сдачей его можно заменить своим текстом. Абзацы помечены комментарием `Personal memory draft`.

## Структура

- `index.html` — карточки, встроенные SVG-сердечки и символ дискеты, диалог.
- `styles/variables.css` — переменные цветов, шрифтов, размеров и градиента.
- `styles/style.css` — раскладка, фильтры, состояния кнопок, адаптивность.
- `styles/animations.css` — переходы и анимации сердечек.
- `fonts/` — вариативный Inter и Press Start 2P.
- `images/` — оригинальная иллюстрация из макета и растровые иконки.
- `svg/` — векторная иконка сайта.
- `scripts/like.js` — исходная логика Практикума, без изменений.
- `scripts/interactions.js` — открытие диалога и доступные состояния кнопок.
